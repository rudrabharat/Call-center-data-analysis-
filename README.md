# Call-center-data-analysiCall Center Dashboard – README

Project Overview

This project is an Excel-based Call Center Dashboard created to analyze customer service call data and visualize key performance metrics. The dashboard helps monitor call volume, customer satisfaction, sentiment, response times, and regional performance.

Dataset

The dataset contains information such as:

Customer Name

Sentiment

CSAT Score

Call Date

Call Reason

City and State

Communication Channel

Response Time

Call Duration

Call Center Location


Dashboard Features

KPI Cards

Total Number of Calls

Average CSAT Score

Average Call Duration


Charts and Visualizations

Line Chart: Total Calls by Call Day

Bar Chart: Calls by Customer Sentiment

Bar Chart: Calls by State

Chart: Calls by City

Call Distribution Analysis

Call Reason Analysis


Key Insights

Tracks daily call volume trends.

Identifies the most common customer sentiment.

Measures customer satisfaction using CSAT scores.

Compares call performance across different states and cities.

Highlights major reasons for customer calls.
